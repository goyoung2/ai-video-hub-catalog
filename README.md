# AI Video Hub — Public Catalog

AI Video Hub 확장 프로그램의 무료 AI 영상 생성 서비스 조사 데이터 공개 저장소입니다.

- **feeds/catalog.json**: 조사된 서비스·모델 경로 127건 (서비스명, 링크, 무료 제공 조건)
- **feeds/updates.json**: 검토할 무료 정책 변경사항과 출처
- **feeds/inbox/*.json**: 예약 조사에서 제출하는 신규 변경 제안
- **GitHub Actions**: JSON 검증, 중복 제거, updates.json 자동 게시

## 공개 주소

- https://raw.githubusercontent.com/goyoung2/ai-video-hub-catalog/main/feeds/catalog.json
- https://raw.githubusercontent.com/goyoung2/ai-video-hub-catalog/main/feeds/updates.json

운영사 안내와 실제 무료 영상 생성·다운로드 결과는 다를 수 있습니다. 업데이트는 먼저 검토 대상이며, 기존 사용자의 계정과 개인 사용 기록은 이 저장소에 저장하지 않습니다.
